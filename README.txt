GAMEX Gaming Website
=====================

FILES
- index.html
- style.css
- script.js

HOW TO USE
1. Upload all files to your hosting service.
2. Make sure index.html is in the main/public folder.
3. Open the website URL.

This is a front-end demo. Login, registration, news, tournaments and accounts are visual/demo features. A backend/database is required for real user accounts and data.

The design uses CSS-generated artwork, so there are no extra image files required.
